# 规则与数字（真源摘要）

本文件解释 templates/style.json 里每个数字从哪来。改参数前先看这里。

## 1. 六条参考片（逐帧测量）

| 片 | 画幅 | 时长 | 切点/分 | 平均镜长 | 字幕字高/画高 |
|---|---|---|---|---|---|
| A 竖屏财经口播 | 1080x1920 | 395s | 24.0 | 2.50s | 3.2% |
| B 横屏医药信息流 | 1280x720 | 683s | 25.0 | 2.37s | 6.2% |
| C 剪映录屏教程 | 2304x1440 | 230s | 2.6 | 23.0s | 8.8% |
| D 4K 竖屏科普 | 2160x3840 | 146s | 17.3 | 3.40s | 3.2% |
| E 39 秒情感口播 | 1440x2560 | 39s | 27.5 | 2.07s | 5.9% |
| F 心理长口播（16:9 塞竖屏） | 720x1280 | 243s | 9.1 | 6.41s | 2.3% |

结论：24-25 切/分是信息型口播的基线；情感型更快（27）；论证型更慢（9-17）；录屏型没有切点。

## 2. 版式（竖屏）

- 画布 1080x1920；字幕基线 73.5% 画高（A 片实测 1335-1400 / 1920 = 70-73%）。
- 字号 = 画高 2.8%（54px）。B 片横屏要 6.2%，因为横屏更矮；竖屏不要跟着放大。
- 颜色：白字 + 2px 暗描边；一行最多 3 色；不用底板（除了录屏教程那种青绿圆角条）。
- 行宽上限 90% 画宽；超过就减字号或断行。
- 关键词角色：number（含数字）=金、verdict（其实/真正/关键/问题/风险…）=红、concept（词典实词）=青、entity（专名/拉丁）=紫；同一行撞色用 ramp=[number, concept, entity, verdict] 换色。

## 3. 重点级别

- L1：普通行，字幕照常，最多一个词上色。
- L2：有数字或两个以上关键词，加 impact 音效，可在句首 tick。
- L3：强转折（其实/真正/本质/关键/唯一/根本/真相/答案）+ 关键词，或数字与判词同句 -> 换版式做海报帧。
- 海报帧间隔 ≥ typography.poster_every_s（默认 8 秒）；20 秒内至少一个。

## 4. 层级排版（来自三条教学片）

- 四层：底字（cue）、重点信息（彩色词）、框架概要（海报帧的 kicker 与副题）、关键词（四角标签）。
- 同屏不超过两层文字；海报帧出现时，底字可以继续，但不要再叠大字。
- 海报帧两种构图：
  - stack（上下式）：kicker 一行 -> 细线 -> 大主体 -> 副题 -> 再一条细线；主体占画高 7%，kicker 1.9%，副题 2.3%。
  - corner（四角式）：主体居中 7.5%，四个角放关键词标签（每个上方 52px 短线），标签 2%。
- 每一帧都要像一张海报：留白、对齐、两色以内为主。

## 5. 时长与声音

- 语速：finance 7.0 字/秒、emotion 6.8、slow 6.2；给了旁白就按真实时长整体缩放。
- 句末停 0.18 秒，逗号 0.06 秒，行内 0.03 秒；单行不短于 0.8 秒。
- 音效：whoosh 0.42s、impact 0.55s、riser 0.95s、tick 0.08s；音量 0.12-0.34。
- 人声 -16..-14 LUFS；BGM -30dB 垫底。

## 6. 主题色板（7 套）

finance 金红青蓝 / emotion 暖金珊瑚紫 / medical 赭金砖红青 / tech 亮黄粉青 / health 橙红绿蓝 / education 黄红蓝紫 / generic 通用金红青灰蓝。

主题按全篇词表命中数判定，最高分且 ≥3 才采用，否则 generic。判定结果写进 plan.json 的 theme 字段，可以 --theme 覆盖。

## 7. 质检红线

- 字幕覆盖 < 85%：稿子有漏行或时长没对齐。
- 一行 > 3 色：role 分配错，检查 plan.json 的 kw。
- 海报间隔 > 14 秒：poster_every_s 太大或 L3 太少。
- 单镜 > 3.4 秒且无运动：加页面动画或提高切点密度。
- 响度 < -22 或 > -10 LUFS：旁白电平不对。
